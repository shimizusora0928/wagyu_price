# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
リモートリポジトリは、ネット上に配置して複数人で共有するためのリポジトリ
ローカルリポジトリは、開発者一人ひとりが作業するために各々のPC上に配置するリポジトリ

## プッシュとマージの違いは何でしょうか？
プッシュは、自分のパソコンにある作業履歴をリモートリポジトリにアップロードすること
マージは、別々に分かれていたブランチを、１つに統合すること

## コミットとプッシュの違い
コミットは、自分のパソコン内の作業履歴を保存することで、この時点ではリモートリポジトリには反映されていない
プッシュを行うことで、その作業履歴をアップロードできる

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
変更内容が正確にわかるようなものにすることが最適

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
ローカルでのマージは、自分のパソコン上でのブランチ統合なので、コードレビューや他の人の承認なしに行える
プルリクエストでのマージは、リモートリポジトリへ変更内容を取り込む前に、他の人にコードを確認してもらうプロセスが発生する
コードレビューや承認を経て、リモートリポジトリに統合される

## コンフリクトを起こしてしまった場合、どう対処すべきですか？
先にマージされた変更内容を取り込むか、後にマージしようとしている変更内容を取り込むか、
どちらの変更内容も取り込むかの３つの方法で対応する
エディタで変更内容を取り込み、取り込み作業が終わり次第コミットする
